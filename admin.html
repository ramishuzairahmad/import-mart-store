IMPORT MART — Admin

Products add / edit / delete karein — Publish dabate hi store 1 minute mein update ho jayega.

1. GitHub Connection

Token sirf isi browser mein save hota hai (localStorage) — kahin aur nahi bheja jata, sirf GitHub ko jata hai. Token banane ke liye: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → repo import-mart-store par Contents: Read and write. Token na ho to neeche "Download catalog.json" se file download karke bhej dein.

2. Products (0)

Abhi koi product nahi — neeche se naya product add karein.

3. Naya Product Add Karein

Photo chunein — khud hi chhoti (1200px) karke upload hogi. Edit karte waqt photo na badalni ho to khaali chhodein, purani photo rehti hai.

4. Publish — Store Par Lagayein

Publish dabate hi catalog.json (aur nayi photos) GitHub repo mein save hongi aur Cloudflare khud store ko dobara deploy kar dega — taqreeban 1 minute mein live.

Publish ke baad store kholein aur refresh karein.
